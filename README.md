# Healthcare Operations & Revenue Analytics Dashboard

## Project Overview

This project is an interactive Healthcare Analytics Dashboard developed using Microsoft Power BI. The main objective is to analyze healthcare operations, patient appointments, doctor performance, department performance, and revenue generation.

The dashboard provides useful business insights through interactive visualizations, KPIs, charts, and filters to support data-driven decision-making in healthcare organizations.

## Dashboard Pages

### 1. Healthcare Executive Overview
- Total Patients
- Total Appointments
- Completed Appointments Percentage
- Cancellation Percentage
- Total Revenue
- Average Patient Rating
- Monthly Revenue Trend

### 2. Healthcare Revenue and Performance
- Revenue Analysis
- Average Revenue per Appointment
- Department Filters
- Location Filters
- Insurance Type Analysis
- Date Filters

### 3. Department Performance Analysis
- Department-wise Revenue
- Revenue Target vs Actual Revenue
- Department Revenue Status
- Average Patient Rating by Department
- Department-wise Performance Comparison

### 4. Doctor Performance Analysis
- Doctor-wise Total Appointments
- Completed Appointments Percentage
- Doctor-wise Revenue
- Average Patient Rating
- Doctor Performance Comparison

## Data Model

The project uses a relational data model containing the following tables:

- Patients
- Appointments
- Billing
- Doctors
- Departments
- Date
- Staff
- Feedback

Relationships between these tables help connect healthcare operational and financial information for analysis.

1. Analyze overall healthcare operational performance.
2. Monitor appointment completion and cancellation rates.
3. Evaluate doctor-wise performance.

6. Analyze revenue trends and patient feedback.
